# Мой рацион — файлы обновлений

Этот публичный репозиторий используется только как канал доставки обновлений личного Android-приложения «Мой рацион».

Здесь нет исходного кода приложения и нет приватного ключа подписи. GitHub Actions приватного репозитория `klimutka/moy-ratsion` публикует сюда:

- `update.json` — номер версии, URL APK, SHA-256 APK, отпечаток сертификата и список изменений;
- APK-файлы как assets GitHub Releases.

Не загружайте сюда исходный код, keystore, пароли или GitHub-токены.
